# Design Gate Adapter for Antigravity

- All user-facing UI/UX changes must pass the 6-stage Design Gate:
  1. DESIGN: Specification & design token alignment.
  2. PREVIEW: Interactive rendering or visual mock.
  3. REVIEW: Aesthetic & accessibility check.
  4. HUMAN APPROVAL: User confirms visual direction.
  5. IMPLEMENTATION: Code written to standards.
  6. VISUAL QA: Playwright / Screenshot verification.
- Canonical design specifications are located in [Docs/Design/DESIGN_SYSTEM.md](file:///f:/APP/Ikame/Word+Document_+DOCX,+PDF,+XLSX_311200_APKPure/Docs/Design/DESIGN_SYSTEM.md).
